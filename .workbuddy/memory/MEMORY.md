# 忆伴项目 · 长期约定

## 项目定位
面向阿尔茨海默病早中期患者的「人生回忆录 + 日常辅助」微信小程序（毕设项目）。
需求基准：《忆伴_PRD_最终版_V1.1》（21 章 + 附录 A/B）。
目录里的 `产品需求文档_PRD.md`（v1.0）和 `忆伴_PRD_v1.3`（AI 陪伴/写日记方向）**均不作为范围依据**。

## 硬性边界（PRD 附录 B，不得越界）
- 第一版**不做**：AI 记忆陪伴聊天、RAG 知识库、AI 识别图片人物、AI 自动决定分类、AI 自动写人生故事、病情评估/诊断/用药建议、家属独立 Web 端、复杂族谱、多联系人轮询
- AI **唯一**允许用法：对家属填写的**文字描述**做关键词标签提取（Mock 实现 + 可注入失败）
- 未选主要分类禁止保存回忆（AC-07）；同一患者仅一个紧急联系人（AC-12）；不虚构任何缺失信息

## 技术约定
- HBuilderX 工程，**无 package.json** → **零 npm 依赖**，不能用 `@/` 别名（easycom 规则里的 `@/` 除外）
- 页面统一 2 层深 `pages/模块/页面.vue`，引用统一 `../../store/index.js`
- 全局样式变量放根 `uni.scss`（只放变量，不放规则/mixin）；mixin 放 `styles/_mixins.scss`
- 运行时字号用 **CSS 变量 + 三档根 class**（md/lg/xl），scss 变量是编译期常量做不了动态字号
- tabBar 页之间必须 `uni.switchTab`；Tab 页刷新数据在 `onShow`（tabBar 页不触发 onLoad）
- 数据出入口唯一：`services/api.js`（Mock），换真后端只改这一层
