## 四、语音 / 包体 / 媒体策略

### 1. 语音朗读：Mock 演示模式（WechatSI 已弃用）
- **弃用原因**：微信同声传译插件实测无法添加授权；其余小程序 TTS 插件生态不成熟；腾讯云 / 讯飞 / 百度 TTS 均需服务端存放 SecretKey，与「只做前端 + Mock」冲突。
- **当前实现**：`services/tts.js` 演示模式 —— 不发声，但完整模拟「开始 → 进度 → 结束」，UI 交互可演示；`isAvailable()` 恒为 `false`，页面走「文字优先」降级，**不假装有声音**。
- **升级路径（换真 TTS 只改 `services/tts.js`，调用方不变）**：
  - A. 腾讯云 TTS + 微信云函数中转（音色好、支持长文本；需开云开发，SecretKey 放云函数环境变量）
  - B. 固定话术（问候 / 用药播报 / 章节名）用 edge-tts 本地生成 mp3 放 `static/`，动态文案仍走 A
- **音量**：`store.ui.volume` 已持久化，`tts.setVolume()` 在 App 启动时恢复；只声称应用内音量，不声称系统音量（PRD 14.2）。

### 2. 包体与媒体：本地素材 + 分包，OSS 延后
| 问题 | 结论 |
| --- | --- |
| 现在包体多大？ | **221KB / 2MB = 10.8%**，绰绰有余，暂时不需要任何外部存储 |
| OSS 现在用吗？ | **不用**。Mock 阶段本地占位图足够；且 OSS 需要先在公众平台配 `downloadFile` / `uploadFile` 合法域名，还要处理密钥安全（AK/SK 不能放前端，需 STS 临时密钥或云函数签发） |
| OSS 什么时候用？ | **S3 家属端上传回忆媒体**时。届时加 `services/upload.js` 抽象：Mock 实现先跑通，换真 OSS（腾讯云 COS 或阿里云 OSS）只改这一个文件 |
| 分包呢？ | **采用**。等 S1 页面落地时在 `pages.json` 配 `subPackages`：主包 = 3 个 Tab + 回忆录核心流（tabBar 页按微信规定必须在主包）；分包 = `pages/past`（看看从前）/ `pages/training`（脑力小时光）/ `pages/familycare`（家属管理）。限制：主包 2MB、单分包 2MB、总计 20MB；**共享素材一律放主包 `static/`**（主包不能引用分包资源） |

### 3. 仍需要你做的一件事
**真机预览前配置 `downloadFile` 合法域名**：`cdn.jsdelivr.net`（宋体字体源，见「已知偏差 4」）。
微信开发者工具里可勾选「不校验合法域名」先跑通，真机预览前必须配。
