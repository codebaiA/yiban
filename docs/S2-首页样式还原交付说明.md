1. **顶部**：自定义导航，内容贴顶；状态栏安全区 → 日期胶囊（青绿 `#E5F2EB`）+ 问候语（`54rpx` 墨绿黑）。**去掉了原来的顶部患者头像**（设计稿无）。

3. **下方双栏**：
   - 左：**脑力小时光**青绿大卡（`#57B5A5`，`360×579`）——标题 + 小播放角标 + 两行文案 + 白色大播放圆。
   - 右上：**呼叫女儿**橙卡（`#FF7A29`）——女儿头像 + 电话小圆 + 「呼叫女儿」。
   - 右下：**今日提醒**白卡——铃铛图标 + 「今日提醒」+ 吃药内卡（橙圆药丸图标 + 药名 + 时间 + 待确认/已确认）。
4. **自定义 TabBar**：首页绿色胶囊（选中态）、中间「我的回忆」悬浮、右侧「我的」；用 `getCurrentPages` 判断当前页高亮，`uni.switchTab` 切换。

6. **字号**：沿用 CSS 变量三档（`var(--yb-fs-*)`），功能与字号切换不受影响。
